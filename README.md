# Conway's Game of Life

A small and still crude implementation of Conway's Game of Life using Raylib and C++.


## Usage

The starting configuration can be edited with the mouse and the simulation can be started and stopped with the spacebar.
A random configuration can be generated with _R_, the simulation speed can be increased and decreased with _UP_ and _DOWN_ respectively. Everything in the configuration can be canceled with _C_. The grid can be hidden or shown with _G_.
